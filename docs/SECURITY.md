## حدود معروفة
- **الأنماط المضمنة (CSS):** CSP يسمح بها (`style-src 'unsafe-inline'`) لأن مكتبة الرسوم تحتاجها. السكربتات مقيدة بالكامل.
- **تحديد المحاولات:** يعتمد على قاعدة البيانات. لا يوجد جدار حماية تطبيقات (WAF) أمام الخدمة، ويمكن إضافة Cloudflare لاحقًا.
- **رموز الاسترداد للتحقق الثنائي:** محفوظة بتجزئة SHA-256، وهي عشوائية بقوة تقارب 50 بت لكل رمز ومحدودة بخمس محاولات لكل تحدٍ.
- **فحص الاختراق:** لم يُجرَ فحص اختراق خارجي مستقل. يوصى به قبل التشغيل ببيانات حقيقية.
