# النسخ الاحتياطي والاسترجاع — ذكي ERP

## النسخ
1. **يدوي (في أي وقت):** النظام ← الإدارة ← «النسخ الاحتياطي» (لمسؤول النظام فقط).
   اختر كلمة سر (12 حرفًا على الأقل) ← «تنزيل النسخة». ملف `.zakibak` مشفّر فيه كل البيانات والملفات المرفوعة.
   احفظه خارج الجهاز (Google Drive / فلاشة)، واحفظ كلمة السر منفصلة — بدونها لا يُفتح الملف.
2. **أسبوعي تلقائي بالإيميل:** يعمل ضمن المهمة اليومية (Render Cron) مرة كل 7 أيام، بعد ضبط متغيرات البيئة في خدمتي `zaki-erp` و`zaki-erp-daily`:
   - `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` (صندوق بريد الشركة)
   - `BACKUP_PASSPHRASE` كلمة سر التشفير (12+ حرفًا، تُحفظ لدى الإدارة)
   - `BACKUP_EMAIL` بريد أو أكثر لاستلام النسخ (مفصولة بفواصل)
   الإيميل يحتوي قاعدة البيانات فقط؛ الملفات المرفوعة في النسخة اليدوية.

## الاسترجاع (عند أي طارئ)
1. أنشئ قاعدة PostgreSQL جديدة فارغة، وضع رابطها في `DATABASE_URL`.
2. بنفس إصدار الكود: `npx prisma migrate deploy` (بدون seed).
3. فحص الملف (بدون كتابة):
   `RESTORE_PASSPHRASE='كلمة السر' npm run backup:restore -- zaki-erp-backup-YYYY-MM-DD.zakibak --check`
4. الاسترجاع (والملفات تُكتب في `STORAGE_DIR`):
   `RESTORE_PASSPHRASE='كلمة السر' npm run backup:restore -- zaki-erp-backup-YYYY-MM-DD.zakibak`
5. شغّل الموقع على القاعدة الجديدة. الجلسات لا تُنسخ، فيسجل الجميع الدخول من جديد.

الاسترجاع يرفض قاعدة فيها بيانات أو بإصدار ترحيلات مختلف (لحماية البيانات)، ويعيد تفعيل كل الحمايات (سجل التدقيق والمدفوعات المعتمدة) بعد الإدخال.
