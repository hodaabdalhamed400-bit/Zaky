# قائمة اختبار المستخدمين (UAT)

تُنفَّذ على بيئة النشر التجريبي **ببيانات تجريبية فقط**. ضع ✓ أو اكتب الملاحظة. يفضل أن ينفذ كل قسم موظف بالدور المذكور.

## مسؤول النظام
- [ ] الدخول لأول مرة: تغيير كلمة المرور المؤقتة ثم تفعيل التحقق الثنائي، وحفظ رموز الاسترداد.
- [ ] إنشاء مستخدم لكل دور، وتخصيص الفروع، ثم تعطيل مستخدم والتأكد أنه خرج فورًا.
- [ ] مراجعة مصفوفة الصلاحيات، ومراجعة سجل التدقيق.
- [ ] إعادة تعيين التحقق الثنائي لمستخدم آخر.

## الإدارة العليا
- [ ] لوحة التحكم: الأرقام منطقية، والرسوم والفلاتر (الفرع والفترة) تعمل.
- [ ] تعديل بيانات فرع (العنوان، رابط الخريطة، المدير) وتغيير حالته.
- [ ] إنهاء عقد مبكرًا بكل سياسة، والتحقق من الأقساط.
- [ ] كل التقارير الثمانية، وتصدير Excel وPDF وفتحهما.

## مدير الفرع
- [ ] لا يرى إلا فرعه (الفروع، الوحدات، العملاء، العقود، التحصيل، التقارير).
- [ ] إضافة أدوار المبنى ووحدات (مكتب خاص ومكتب مشترك)، وتجربة "حفظ وإضافة أخرى".
- [ ] إنشاء عقد بأكثر من وحدة، وإرساله واعتماده، والتحقق من جدول الأقساط (يوم الاستحقاق ومبلغ الضريبة).
- [ ] محاولة عقد متعارض على نفس الوحدة: يجب أن يُرفض.
- [ ] رفع نسخة العقد الموقعة، وطباعة نسخة العقد.
- [ ] تسجيل دفعة واعتمادها، وطباعة الإيصال.

## المحاسب
- [ ] دفعة جزئية، ودفعة على أكثر من قسط، ومحاولة دفع زائد (يجب أن تُرفض).
- [ ] تسجيل نفس رقم الحوالة مرتين (يجب أن يُرفض).
- [ ] عكس دفعة وتسوية (خصم أو إعفاء)، ومراجعة الأرقام في صفحة التحصيل.
- [ ] تقرير المتأخرات ومطابقته يدويًا مع عقدين.

## موظف المبيعات والتشغيل
- [ ] إضافة عميل محتمل، وتنبيه التكرار عند نفس الجوال.
- [ ] رقم الهوية والمستندات الحساسة محجوبة عن موظف المبيعات.
- [ ] موظف التشغيل يغيّر حالة وحدة إلى "صيانة".

## الإشعارات
- [ ] الإشعارات تصل للدور الصحيح في الفرع الصحيح، وتختفي عند إنجاز الإجراء.

## الجوال
- [ ] تنفيذ الدخول والبحث عن عميل وتسجيل دفعة من جوال حقيقي (iPhone وAndroid).
