# دليل التشغيل والتسليم

## المهام الدورية
| المهمة | التكرار | الطريقة |
|---|---|---|
| المهمة اليومية (حالات العقود، مسودات التجديد، الإشعارات) | يوميًا 00:15 بتوقيت الرياض، تلقائيًا | خدمة Cron في Render (`npm run job:daily`) |
| نسخة احتياطية مستقلة مشفرة | أسبوعيًا على الأقل | `npm run backup` ثم التشفير والنقل خارج Render |
| تمرين استعادة | شهريًا | `npm run restore` إلى قاعدة فارغة ثم `npm run backup:verify` |
| مراجعة سجل التدقيق والمستخدمين النشطين | شهريًا | صفحتا "سجل التدقيق" و"المستخدمون" |
| تحديث الاعتماديات الأمنية | شهريًا | `npm audit` ثم الاختبارات كاملة قبل النشر |

## حالات شائعة
- **موظف ترك العمل:** المستخدمون ← تعطيل الحساب، فتُنهى جلساته فورًا. لا يُحذف الحساب، لأن سجل التدقيق مرتبط به.
- **موظف فقد جواله:** يتحقق مسؤول النظام من هويته، ثم صفحة المستخدم ← "إعادة تعيين التحقق الثنائي". يُطلب منه التفعيل عند الدخول التالي.
- **نسي كلمة المرور:** صفحة المستخدم ← إعادة تعيين كلمة المرور. تُعطى له كلمة مؤقتة يغيّرها عند الدخول.
- **مسؤول النظام الوحيد فقد الوصول:** من Render Shell شغّل `npm run admin:create` لإنشاء مسؤول جديد، ثم أعد تعيين الحساب القديم.
- **دفعة سُجلت خطأ بعد اعتمادها:** عكسها مع ذكر السبب، ثم سجّل الصحيحة. لا يمكن حذفها.
- **فرع جديد:** الفروع ← فرع جديد بحالة "قيد التجهيز"، ثم أضف الأدوار والوحدات، ثم غيّر الحالة إلى "عامل" عند الافتتاح.

## تعديل الصلاحيات أو الإعدادات
- **الصلاحيات:** في `src/lib/rbac/permissions.ts`، ثم `npm run db:seed`، ثم النشر.
- **الإعدادات:** جدول `system_settings`. أهمها:
  - أيام التنبيه: `contract.expiry_alert_days`.
  - أيام مسودة التجديد: `contract.renewal_draft_days`.
  - أدوار التحقق الثنائي: `security.mfa_required_roles`.
